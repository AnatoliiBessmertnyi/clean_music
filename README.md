# Audio Cleaner

Скрипт для автоматической очистки и переименования аудиофайлов.

## Возможности

- 🧹 Очистка от мусорных тегов (vksaver, muzmo.ru и др.)
- 🏷️ Нормализация тегов (feat., разделители исполнителей)
- 📝 Переименование по тегам или тегов по имени файла
- 🔍 Поиск и удаление дубликатов
- 👥 Нормализация имен исполнителей
- 🛡️ Обработка недопустимых символов в именах

## Установка

```bash
pip install -e .
```

## Использование

```bash
# Обычный режим
python main.py

# Сухой прогон (без изменений)
python main.py --dry-run

# С отладочным выводом
python main.py --debug
```

## Тестирование

```bash
pytest tests/ -v
```

## Разработка

```bash
# Установка dev-зависимостей
pip install -e ".[dev]"

# Линтинг
ruff check .

# Форматирование
ruff format .

# Проверка типов
mypy .
```

## Поддерживаемые форматы

- MP3
- M4A/MP4
- FLAC
- OGG
- WMA
